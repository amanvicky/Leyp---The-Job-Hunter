# Leyp Phase 1 — Walking Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the complete architectural skeleton of Leyp — schema, auth, the two mutation contracts, the audit test, the job runner, the AI provider registry and the design system — so phases 2–6 fill interfaces that never change.

**Architecture:** Next.js 16 App Router with React Server Components; PostgreSQL in Docker, app running natively on Node. Every mutation passes through `action()`, every route through `route()`, and a test walks the tree to prove no route escapes. AI providers are a runtime value behind a registry with all four adapters present from the start.

**Tech Stack:** Next.js 16.4.3, React 19.3.1, TypeScript 5 strict, Prisma 7.10.1, PostgreSQL 18, Tailwind 4, zod 4, Vitest 5, Playwright 1.64, `@node-rs/argon2`, `jose`, `playwright-core`.

**Spec:** `docs/superpowers/specs/2026-11-02-leyp-design.md`

## Global Constraints

- Node 24 or newer; npm as the package manager (not yarn — the spec's Windows-native goal favors npm's simpler tooling story).
- TypeScript `strict: true`; no `any` in exported signatures.
- Server code reads configuration only from the validated `env` object in `src/lib/env.ts`; never `process.env` directly.
- Every mutation uses `action()`; every route handler uses `route()`. No exceptions beyond sign-in and sign-out.
- Secrets are stored encrypted under class-specific HKDF keys derived from `APP_SECRET`; never logged, never serialized to the client.
- Database tests run against a database whose name ends in `_test`; e2e against one ending in `_e2e`. Both refuse otherwise.
- Tests never reach the real network; fakes are local servers addressed by test-only env vars.
- No telemetry, no usage ping.
- Text fields the user fills default to `""`, never null.
- Money is stored as `Int` minor units (paise) or nullable when unparseable — never as a float.
- Every commit message uses Conventional Commits (`feat:`, `fix:`, `test:`, `chore:`).

```ts
import { z } from "zod";

export class EnvError extends Error {}

const HASH = /^argon2id:m=\d+,t=\d+,p=\d+:[A-Za-z0-9+/=]+:[A-Za-z0-9+/=]+$/;

const schema = z.object({
  APP_PASSWORD: z.string().regex(HASH, "APP_PASSWORD must be an argon2id hash, not a password"),
  APP_SECRET: z.string().min(32, "APP_SECRET must be at least 32 characters"),
  DATABASE_URL: z.string().min(1, "DATABASE_URL is required"),
  NODE_ENV: z.enum(["development", "test", "production"]).default("development"),
  AI_PROVIDER: z.string().optional(),
  AI_URL: z.string().optional(),
  AI_MODEL: z.string().optional(),
  AI_KEY: z.string().optional(),
  AI_TIMEOUT_SECONDS: z.coerce.number().int().positive().optional(),
  JOBS_SOURCE: z.string().optional(),
  TEST_DATABASE_URL: z.string().optional(),
  E2E_DATABASE_URL: z.string().optional(),
});

export type Env = z.infer<typeof schema>;

export function loadEnv(source: Record<string, string | undefined>): Env {
  const result = schema.safeParse(source);
  if (!result.success) {
    const first = result.error.issues[0];
    const name = String(first?.path[0] ?? "environment");
    throw new EnvError(`${name}: ${first?.message ?? "is invalid"}`);
  }
  return result.data;
}

export const env = loadEnv(process.env);
```

Note: `loadEnv` takes its source as a parameter so tests never depend on the real process environment; the exported `env` is the single call site that reads `process.env`.

const TABLES = [
  "Job", "LoginThrottle", "EmailMessage", "GoogleAccount", "StartupBlock",
  "Startup", "AgentCandidate", "PostingSearch", "PostingScore", "Posting",
  "Note", "ChatMessage", "DocumentVersion", "Document", "StatusEvent",

export async function resetDatabase(opts: { url?: string } = {}): Promise<void> {
  const url = opts.url ?? env.TEST_DATABASE_URL ?? "";
  if (!url) throw new Error("TEST_DATABASE_URL is not set");
  if (!/_test$/.test(new URL(url).pathname)) {
    throw new Error(`Refusing to reset: the database must end in _test (got ${url})`);
  }
  const client = new Client({ connectionString: url });
  await client.connect();
  try {
    const list = TABLES.map((t) => `"${t}"`).join(", ");
    await client.query(`TRUNCATE TABLE ${list} RESTART IDENTITY CASCADE`);
  } finally {
    await client.end();
  }
}

```ts
// src/lib/auth/password-hash.ts
import { hash, verify } from "@node-rs/argon2";

const PARAMS = { memoryCost: 19456, timeCost: 2, parallelism: 1 } as const;

export async function hashPassword(plain: string): Promise<string> {
  const encoded = await hash(plain, { ...PARAMS, outputLen: 32 });
  // @node-rs/argon2 returns $argon2id$v=19$m=...,t=...,p=...$salt$hash
  const [, , , params, salt, digest] = encoded.split("$");
  const m = /m=(\d+)/.exec(params ?? "")?.[1] ?? String(PARAMS.memoryCost);
  const t = /t=(\d+)/.exec(params ?? "")?.[1] ?? String(PARAMS.timeCost);
  const p = /p=(\d+)/.exec(params ?? "")?.[1] ?? String(PARAMS.parallelism);
  return `argon2id:m=${m},t=${t},p=${p}:${salt}:${digest}`;
}

export async function verifyPassword(plain: string, stored: string): Promise<boolean> {
  const [, params, salt, digest] = stored.split(":");
  const m = /m=(\d+)/.exec(params ?? "")?.[1];
  const t = /t=(\d+)/.exec(params ?? "")?.[1];
  const p = /p=(\d+)/.exec(params ?? "")?.[1];
  if (!m || !t || !p || !salt || !digest) return false;
  const encoded = `$argon2id$v=19$m=${m},t=${t},p=${p}$${salt}$${digest}`;
  return verify(encoded, plain);
}
```

The custom `argon2id:m=…` format exists because `.env` parsers expand `$`, which corrupts the conventional encoded string.

```ts
// src/lib/secrets.ts
import { createCipheriv, createDecipheriv, hkdfSync, randomBytes } from "node:crypto";

export type SecretClass = "AI_KEY" | "JOB_SOURCE_KEY" | "GOOGLE_TOKEN";

function key(secret: string, cls: SecretClass): Buffer {
  return Buffer.from(hkdfSync("sha256", secret, "Leyp", `secret:${cls}`, 32));
}

export function encrypt(plaintext: string, cls: SecretClass, secret: string): string {
  const iv = randomBytes(12);
  const cipher = createCipheriv("aes-256-gcm", key(secret, cls), iv);
  const body = Buffer.concat([cipher.update(plaintext, "utf8"), cipher.final()]);
  const tag = cipher.getAuthTag();
  return Buffer.concat([iv, tag, body]).toString("base64");
}

export function decrypt(payload: string, cls: SecretClass, secret: string): string {
  const raw = Buffer.from(payload, "base64");
  const iv = raw.subarray(0, 12);
  const tag = raw.subarray(12, 28);
  const body = raw.subarray(28);
  const decipher = createDecipheriv("aes-256-gcm", key(secret, cls), iv);
  decipher.setAuthTag(tag);
  return Buffer.concat([decipher.update(body), decipher.final()]).toString("utf8");
}
```

// src/lib/auth/session.ts
import { SignJWT, jwtVerify } from "jose";
import { cookies } from "next/headers";
import { redirect } from "next/navigation";
import { createHash } from "node:crypto";
import { env } from "@/env";

const COOKIE = "leyp_session";
export type Session = { fingerprint: string; expiresAt: number };

function signingKey(): Uint8Array {
  return new Uint8Array(createHash("sha256").update(`session:${env.APP_SECRET}`).digest());
}

/** Invalidates every session when the password hash changes. */
function fingerprint(): string {
  return createHash("sha256").update(env.APP_PASSWORD).digest("base64url").slice(0, 16);
}

export async function createSession(remember = false): Promise<string> {
  const seconds = remember ? 30 * 24 * 3600 : 24 * 3600;
  return new SignJWT({ fingerprint: fingerprint() })
    .setProtectedHeader({ alg: "HS256" })
    .setIssuedAt()
    .setExpirationTime(`${seconds}s`)
    .sign(signingKey());
}

export async function getSession(): Promise<Session | null> {
  const token = (await cookies()).get(COOKIE)?.value;
  if (!token) return null;
  try {
    const { payload } = await jwtVerify(token, signingKey());
    if (payload.fingerprint !== fingerprint()) return null;
    return { fingerprint: String(payload.fingerprint), expiresAt: Number(payload.exp) * 1000 };
  } catch {
    return null;
  }
}

export async function verifySession(): Promise<Session> {
  const session = await getSession();
  if (!session) redirect("/login");
  return session;
}

export const SESSION_COOKIE = COOKIE;

// src/lib/action.ts
import type { ZodType } from "zod";
import { getSession } from "./auth/session";
import { logServerError } from "./log";

export class ActionError extends Error {}

export type ActionResult<T> =
  | { ok: true; data: T; toast?: string }
  | { ok: false; error: string; fieldErrors?: Record<string, string[]> };

export const GENERIC_ERROR = "Something went wrong. Please try again.";

export function action<TIn, TOut>(
  schema: ZodType<TIn>,
  handler: (input: TIn, ctx: { toast: (message: string) => void }) => Promise<TOut>,
): (raw: unknown) => Promise<ActionResult<TOut>> {
  return async (raw: unknown): Promise<ActionResult<TOut>> => {
    if (!(await getSession())) return { ok: false, error: "Please sign in again." };

    const parsed = schema.safeParse(raw);
    if (!parsed.success) {
      const fieldErrors: Record<string, string[]> = {};
      for (const issue of parsed.error.issues) {
        const key = String(issue.path[0] ?? "_");
        (fieldErrors[key] ??= []).push(issue.message);
      }
      return { ok: false, error: "Please fix the highlighted fields.", fieldErrors };
    }

    let toastMessage: string | undefined;
    try {
      const data = await handler(parsed.data, {
        toast: (message: string) => { toastMessage = message; },
      });
      return toastMessage ? { ok: true, data, toast: toastMessage } : { ok: true, data };
    } catch (error) {
      if (error instanceof ActionError) return { ok: false, error: error.message };
      // Next.js control-flow errors must escape so redirect() and notFound() work.
      if (isNextControlFlow(error)) throw error;
      logServerError("action", error);
      return { ok: false, error: GENERIC_ERROR };
    }
  };
}

function isNextControlFlow(error: unknown): boolean {
  const digest = (error as { digest?: unknown })?.digest;
  return typeof digest === "string" && (digest.startsWith("NEXT_REDIRECT") || digest.startsWith("NEXT_NOT_FOUND"));
}

const JSON_HEADERS = { "content-type": "application/json" };

export function route<C = unknown>(
  handler: (request: Request, context: C) => Promise<Response>,
): (request: Request, context: C) => Promise<Response> {
  return async (request: Request, context: C): Promise<Response> => {
    const origin = request.headers.get("origin");
    if (origin && !sameOrigin(origin, request.url)) {
      return json({ error: "Cross-origin request refused." }, 403);
    }
    if (!(await getSession())) {
      return json({ error: "Please sign in again." }, 401);
    }
    try {
      const response = await handler(request, context);
      if (!response.headers.has("cache-control")) {
        response.headers.set("cache-control", "private, no-store");
      }
      return response;
    } catch (error) {
      logServerError("route", error);
      return json({ error: GENERIC_ERROR }, 500);
    }
  };
}

function sameOrigin(origin: string, url: string): boolean {
  try { return new URL(origin).host === new URL(url).host; } catch { return false; }
}

export function json(body: unknown, status = 200): Response {
  return new Response(JSON.stringify(body), { status, headers: JSON_HEADERS });
}

// src/lib/auth/throttle.ts
import { prisma } from "@/lib/prisma";
import { ActionError } from "@/lib/action";

const WINDOW_MS = 60_000;
const LIMIT = 5;

export async function clientKey(): Promise<string> {
  const { headers } = await import("next/headers");
  const forwarded = (await headers()).get("x-forwarded-for");
  return forwarded?.split(",").at(-1)?.trim() || "local";
}

export async function checkThrottle(): Promise<void> {
  const key = await clientKey();
  const row = await prisma.loginThrottle.findUnique({ where: { key } });
  if (row?.blockedUntil && row.blockedUntil > new Date()) {
    throw new ActionError("Too many attempts. Wait a minute and try again.");
  }
}

export async function recordFailure(): Promise<void> {
  const key = await clientKey();
  const now = new Date();
  const row = await prisma.loginThrottle.findUnique({ where: { key } });
  const fresh = !row || now.getTime() - row.windowStart.getTime() > WINDOW_MS;
  const failures = fresh ? 1 : row.failures + 1;
  const backoff = Math.min(30_000 * 2 ** Math.max(0, failures - LIMIT), 15 * 60_000);
  await prisma.loginThrottle.upsert({
    where: { key },
    create: { key, failures, windowStart: now, blockedUntil: failures >= LIMIT ? new Date(now.getTime() + backoff) : null },
    update: { failures, windowStart: fresh ? now : row.windowStart, blockedUntil: failures >= LIMIT ? new Date(now.getTime() + backoff) : null },
  });
}

export async function clearFailures(): Promise<void> {
  await prisma.loginThrottle.deleteMany({ where: { key: await clientKey() } });
}

import { NextResponse, type NextRequest } from "next/server";

export function proxy(request: NextRequest): NextResponse {
  const nonce = Buffer.from(crypto.randomUUID()).toString("base64");
  const csp = [
    `default-src 'self'`,
    `script-src 'self' 'nonce-${nonce}' 'strict-dynamic'`,
    `style-src 'self' 'unsafe-inline'`,
    `img-src 'self' data: blob:`,
    `font-src 'self'`,
    `connect-src 'self'`,
    `frame-ancestors 'none'`,
    `object-src 'none'`,
    `base-uri 'self'`,
    `form-action 'self'`,
  ].join("; ");

  const headers = new Headers(request.headers);
  headers.set("x-nonce", nonce);
  const response = NextResponse.next({ request: { headers } });
  response.headers.set("content-security-policy", csp);
  response.headers.set("x-content-type-options", "nosniff");
  response.headers.set("x-frame-options", "DENY");
  response.headers.set("referrer-policy", "strict-origin-when-cross-origin");
  response.headers.set("cross-origin-opener-policy", "same-origin");
  response.headers.set("permissions-policy", "camera=(), microphone=(), geolocation=()");
  return response;
}

export const config = {
  matcher: ["/((?!_next/static|_next/image|favicon.ico).*)"],

// src/lib/ai/errors.ts
export class AiError extends Error {
  constructor(message: string, options?: { cause?: unknown }) {
    super(message, options);
    this.name = "AiError";
  }
}

export function messageFor(status: number, provider: string): string {
  if (status === 401 || status === 403) return `Your ${provider} key was rejected. Check it in Settings.`;
  if (status === 429) return `${provider} is rate-limiting requests. Wait a minute and try again.`;
  if (status === 404) return `${provider} does not have that model. Check the model name in Settings.`;

    ignoresSchemas: true,

export function serverAt(baseURL: string): Server | undefined {
  const host = URL.canParse(baseURL) ? new URL(baseURL).hostname : "";
  return SERVERS.find(({ domain }) => host === domain || host.endsWith(`.${domain}`));
}

export function withoutSlashes(text: string): string {
  let end = text.length;
  while (end > 0 && text[end - 1] === "/") end--;
  return text.slice(0, end);
}

export function apiAddress(baseURL: string): string {
  const shape = serverAt(baseURL)?.path;
  if (!shape) return withoutSlashes(baseURL);
  const url = new URL(baseURL);
  url.pathname = shape(withoutSlashes(url.pathname));
  return withoutSlashes(url.href);
}

export function ignoresSchemas(baseURL: string, model: string): boolean {
  return serverAt(baseURL)?.ignoresSchemas === true || model.endsWith("-cloud");
}

// src/lib/ai/providers/openai.ts
import { AiError, messageFor } from "../errors";
import { apiAddress, ignoresSchemas, serverAt } from "./servers";
import type { ChatRequest, Provider } from "../types";

export function openAiProvider(
  config: { url: string; model: string; key?: string; timeoutSeconds?: number },
  deps: { fetchImpl: typeof fetch; sleep: (ms: number) => Promise<void> },
): Provider {
  const address = `${apiAddress(config.url)}/chat/completions`;
  const server = serverAt(config.url);
  const putSchemaInPrompt = ignoresSchemas(config.url, config.model);
  // A local model gets longer than a hosted one: it is slower, but free.
  const timeoutSeconds = config.timeoutSeconds ?? (server ? 120 : 300);

  async function once(request: ChatRequest): Promise<Response> {
    const system = putSchemaInPrompt && request.schema
      ? `${request.system}\n\nAnswer with JSON matching this schema:\n${JSON.stringify(request.schema)}`
      : request.system;

    return deps.fetchImpl(address, {
      method: "POST",
      headers: {
        "content-type": "application/json",
        ...(config.key ? { authorization: `Bearer ${config.key}` } : {}),
        ...(server?.headers?.() ?? {}),
      },
      body: JSON.stringify({
        model: config.model,
        messages: [{ role: "system", content: system }, { role: "user", content: request.user }],
        max_tokens: request.maxTokens ?? 2048,
        ...(request.schema && !putSchemaInPrompt ? { response_format: { type: "json_schema", json_schema: request.schema } } : {}),
        ...(server?.chat ?? {}),
      }),
      signal: AbortSignal.timeout(timeoutSeconds * 1000),
    });
  }

  return {
    name: server?.name ?? "OpenAI-compatible",
    async chat(request: ChatRequest): Promise<string> {
      let response: Response;
      try {
        response = await once(request);
        if (response.status === 429 || response.status === 529) {
          await deps.sleep(60_000);
          response = await once(request);
        }
      } catch (error) {
        if (error instanceof DOMException && error.name === "TimeoutError") {
          throw new AiError(`${server?.name ?? "The model"} took too long to answer (${timeoutSeconds}s). Try a smaller model or a shorter posting.`);
        }
        throw new AiError(`${server?.name ?? "The model"} could not be reached. Check the address in Settings.`, { cause: error });
      }
      if (!response.ok) throw new AiError(messageFor(response.status, server?.name ?? "the provider"));
      const body = (await response.json()) as { choices?: { message?: { content?: string } }[] };
      const text = body.choices?.[0]?.message?.content;
      if (typeof text !== "string") throw new AiError("The model returned no text.");
      return text;
    },
  };
}

// src/lib/jobs/runner.ts
import type { ZodType } from "zod";
import { prisma } from "@/lib/prisma";
import { logServerError } from "@/lib/log";

export type JobContext = { step(message: string): Promise<void> };
type JobDefinition = {
  type: string;
  input: ZodType<unknown>;
  run: (input: unknown, ctx: JobContext) => Promise<unknown>;
};

const registry = new Map<string, JobDefinition>();
export const GENERIC_JOB_ERROR = "Something went wrong. Please try again.";

export function defineJob<In, Out>(spec: {
  type: string;
  input: ZodType<In>;
  run: (input: In, ctx: JobContext) => Promise<Out>;
}): void {
  registry.set(spec.type, spec as unknown as JobDefinition);
}

export function resetJobRegistryForTests(): void {
  registry.clear();
}

export async function startJob(
  type: string,
  input: unknown,
  opts: { key?: string; applicationId?: string } = {},
): Promise<string> {
  if (!registry.has(type)) throw new Error(`Unknown job type: ${type}`);
  const job = await prisma.job.create({
    data: { type, input: input as object, key: opts.key ?? null, applicationId: opts.applicationId ?? null },
  });
  return job.id;
}

export async function runJob(id: string): Promise<void> {
  const job = await prisma.job.findUnique({ where: { id } });
  if (!job) throw new Error(`No job ${id}`);
  const definition = registry.get(job.type);
  if (!definition) {
    await prisma.job.update({
      where: { id }, data: { status: "FAILED", error: GENERIC_JOB_ERROR, finishedAt: new Date() },
    });
    return;
  }

  await prisma.job.update({ where: { id }, data: { status: "RUNNING", startedAt: new Date() } });
  const ctx: JobContext = {
    step: async (message) => { await prisma.job.update({ where: { id }, data: { step: message } }); },
  };

  try {
    const parsed = definition.input.safeParse(job.input);
    if (!parsed.success) throw new Error("Job input failed validation");
    const result = await definition.run(parsed.data, ctx);
    await prisma.job.update({
      where: { id },
      data: { status: "DONE", result: result as object, finishedAt: new Date(), step: null },
    });
  } catch (error) {
    logServerError(`job:${job.type}`, error);
    await prisma.job.update({
      where: { id },
      data: { status: "FAILED", error: GENERIC_JOB_ERROR, finishedAt: new Date() },
    });
  }
}

// src/lib/ai/tasks/extract-posting.ts
import { z } from "zod";
import type { Provider } from "../types";

export const EXTRACT_POSTING_VERSION = "extract-posting@1";

export const extractedSchema = z.object({
  title: z.string(),
  company: z.string(),
  location: z.string(),
  salary: z.string(),
  requirements: z.array(z.string()),
});

export type Extracted = z.infer<typeof extractedSchema>;

const SYSTEM = `You read job postings and extract facts.
Return JSON only, matching this shape exactly:
{"title":string,"company":string,"location":string,"salary":string,"requirements":string[]}
Use "" when the posting does not say. Never invent a value.
List at most 12 requirements, each a short phrase copied from the posting.`;

export async function extractPosting(provider: Provider, text: string, url?: string): Promise<Extracted> {
  const answer = await provider.chat({
    system: SYSTEM,
    user: `${url ? `Posting URL: ${url}\n\n` : ""}${text}`,
    schema: extractedSchema,
    maxTokens: 1024,
  });

  let parsed: unknown;
  try {
    parsed = JSON.parse(stripFence(answer));
  } catch {
    throw new Error("The model's answer was not JSON. Ask it again.");
  }

  const result = extractedSchema.safeParse(parsed);
  if (!result.success) {
    const fields = result.error.issues.map((i) => i.path.join(".")).join(", ");
    throw new Error(`The model's answer did not come back in the expected shape: ${fields}`);
  }
  return result.data;
}

function stripFence(text: string): string {
  const fenced = /```(?:json)?\s*([\s\S]*?)```/.exec(text);
  return (fenced?.[1] ?? text).trim();
}
